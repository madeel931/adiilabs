# ADii Labs

**Build. Ship. Improve.**

ADii Labs is an independent software studio building useful products with Flutter + AI. We focus on utility, performance, and long-term sustainability. Our goal is to create products that solve real problems with a clean architecture and offline-first capabilities.

## Live Website
https://madeel931.github.io/adiilabs/

## Technologies
- Flutter 3+
- Dart
- Material 3
- Web, Android, Desktop Support

## Development

```bash
# Install dependencies
flutter pub get

# Run the project locally
flutter run -d chrome

# Build for Web
flutter build web --base-href "/adiilabs/"
```

## Products
- **InvoiceFlow Pro**: Offline-first invoicing for small businesses.
